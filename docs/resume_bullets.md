## Honest framing notes

- Data is synthetic, generated by a custom event generator (`event_generator/`) — say "synthetic product events," not "real user data," anywhere this project is described.
- The MVP stack (this repo as built) is: FastAPI + MinIO + PySpark + Airflow + Streamlit + Docker. Kafka/Redpanda, Trino, Hive Metastore, and Iceberg are documented as a designed-but-not-implemented "Advanced Version" — don't claim those as built unless you actually add them.
- If you generate and process 1M+ or 5M+ events before an interview, that's a legitimate scale claim — `event_generator/generate_events.py --events 5000000` is built to support it. Test it once locally first so you can speak to runtime and storage size from experience.
